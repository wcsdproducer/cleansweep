# /build-and-deploy — CleanSweep

// turbo-all

## Steps

1. **Typecheck**:
   - `npm run typecheck`

2. **Build**:
   - `npm run build`

3. **Deploy**:
   - `git add -A && git commit -m "deploy: <description>" && git push`

4. **Verify**:
   - Check Firebase App Hosting console for build status.
